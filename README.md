**Хватит ли 2 ГБ RAM для сайта на WordPress?**
Для одного сайта с небольшой базой и парой плагинов — да, при условии кэширования. Если планируете WooCommerce с сотнями товаров или несколько сайтов на одном сервере, берите VPS Basic с 4 ГБ.

**Можно ли установить Windows?**
Образы Windows Server есть в списке при развёртывании. Условия лицензии Microsoft на странице не раскрыты, этот вопрос стоит задать поддержке до заказа.

**Что будет, если ресурсов перестанет хватать?**
Тарифы масштабируются по vCPU, RAM и диску. Ориентир от самого провайдера: держать утилизацию vCPU ниже 80% в пиках, дальше переходить на выделенный сервер.

**Есть ли тестовый период или возврат денег?**
На странице тарифов такие условия не указаны. Это первое, что нужно спросить в поддержке, если вы не готовы рисковать оплатой вслепую.

**Можно ли оплатить российской картой?**
Цены выставлены в евро, способы оплаты в карточках не перечислены. Уточняйте до заказа: для карты МИР это принципиальный момент.
